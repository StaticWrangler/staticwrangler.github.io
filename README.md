# StaticWrangler website

The marketing and support website for StaticWrangler: [staticwrangler.com](https://staticwrangler.com/).

This repository contains the public-facing site only: HTML, CSS, branding and reviewed illustrative screenshots. It contains no provider exports, credentials, actual playlist structure or backend configuration.

The T-Rex and Dream 4K editions are being prepared for a free beta. Support FAQs are available on the site; a dedicated EPGenius Discord support thread will be linked when available.

The site is buildless. GitHub Pages serves `main` from the repository root; `.nojekyll` preserves ordinary static files. The verified custom domain uses HTTPS, and `www.staticwrangler.com` redirects to the root domain. Keep `CNAME` when publishing updates. No analytics, forms or tracking scripts are included.

Typography uses a locally hosted copy of Manrope. Its SIL Open Font License is included in `assets/fonts/OFL-Manrope.txt`.
